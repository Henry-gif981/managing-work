## Before the fix

The same check, run against the pre-update geometry (curves drawn above the cards from the element edge facing the anchor; `npm run check-lines -- --legacy --sizes=1920x1080`), found **98 overlaps in 39 beat views at 1920×1080**. The full list is in `docs/line-overlaps-before.md` and includes the known cases `f2-disbursement` beats 1 and 6 and `f2-me` beat 1.

## What changed (src/primitives/Callout.tsx)

1. The line layer sits **below the content cards** and above the 3D canvas.
2. Lines start on the **nearest edge** of the source element: a text card's inner card, or a table row's outer edge, which is the table edge.
3. Each line is **routed** as a straight line, an elbow or a three-segment detour around every text rectangle, card and HUD box (4 px padding); the shortest clear route wins.
4. Lines have a pale halo and end in a pin.
5. If no route is clear, the beat shows **numbered pins** on the element and at the prop (22 beat views across both sizes).
